# 🌊 Intelligent Marine Buoy Prototype
## 基于 ESP32-S3 的多传感器海洋环境感知浮标样机

## 📌 项目简介

本项目是一款基于 ESP32-S3 微控制器开发的智能浮标原型系统，主要用于采集海洋环境状态数据，实现对浮标姿态、位置以及环境参数的实时感知。

该样机通过多传感器融合方式，实现基础海洋环境监测功能，为后续海洋风险评估、航行辅助决策以及智能导航应用提供数据采集端支持。

目前第一阶段样机主要完成：

- ✅ 微控制器基础平台搭建
- ✅ 姿态传感模块集成
- ✅ 环境气压/高度变化监测
- ✅ GPS定位功能集成
- ✅ 多传感器数据读取与串口输出
- ✅ VSCode + PlatformIO开发环境部署

# 🛠️ Hardware Architecture

## 核心控制单元

| 模块 | 功能 |
|-|-|
| ESP32-S3 | 主控制器，负责传感器数据采集与通信 |
| USB Type-C | 程序烧录与串口调试 |


## 传感器模块

### 1. MPU6050 六轴姿态传感器

功能：

- 三轴加速度检测
- 三轴角速度检测
- 浮标姿态变化监测


接口：

| MPU6050 | ESP32-S3 |
|-|-|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |


---

### 2. BMP280 / BME280 环境传感器

功能：

- 气压检测
- 温度检测
- 高度变化估算

接口：

| BMP280/BME280 | ESP32-S3 |
|-|-|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |
| CSB | 3.3V |
| SDO | GND |


说明：

BMP280/BME280 与 MPU6050 共用 I2C 总线，通过不同设备地址实现多个传感器同时通信。


---

### 3. GPS定位模块

功能：

- 获取实时经纬度
- 获取定位时间
- 为后续路径规划提供位置数据


接口：

| GPS模块 | ESP32-S3 |
|-|-|
| VCC | 电源 |
| GND | GND |
| TX | ESP32 RX |
| RX | ESP32 TX |
