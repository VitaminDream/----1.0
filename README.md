# 浮标样机 V1.1：ESP32-S3 + MPU6050 + BME280/BMP280 + G60 GNSS

这是浮标样机的 **V1.1 版本**。

在 V1.0 的基础上，本版本新增了 **G60 GNSS 定位模块**，并完成了 ESP32-S3、MPU6050、BME280/BMP280 与 GNSS 模块的联合运行测试。

当前版本的目标仍然不是一次性加入所有最终功能，而是先建立一个稳定、可继续扩展的多传感器采集框架。目前已经完成 **运动姿态、环境参数和地理定位数据** 的同步获取，为后续加入无线通信、SD 卡记录、网页可视化和 3D 浮标姿态显示等功能打下基础。

## V1.1 完成什么

1. **ESP32-S3 使用 I2C 总线**

   * `SDA = GPIO8`
   * `SCL = GPIO9`

2. **启动时自动扫描 I2C 总线**

3. **自动寻找 MPU6050**

   * 支持地址 `0x68 / 0x69`

4. **自动识别 BME280 / BMP280**

   * 支持地址 `0x76 / 0x77`

5. **加入 G60 GNSS 定位模块**

   * 使用 UART 串口通信
   * GNSS TX → ESP32-S3 `GPIO18 (RX)`
   * GNSS RX ← ESP32-S3 `GPIO17 (TX)`
   * 默认串口波特率：`9600`
   * 解析标准 NMEA 定位数据

6. **MPU6050 数据输出**

   * X / Y / Z 加速度（m/s²）
   * X / Y / Z 角速度（rad/s）
   * 芯片温度
   * 第一版 roll / pitch 倾角估算
   * 总加速度与动态运动指标

7. **BME280 / BMP280 数据输出**

   * 温度
   * 气压
   * 粗略高度估计
   * 如果识别为 BME280，同时输出湿度

8. **GNSS 定位数据输出**

   * 纬度 Latitude
   * 经度 Longitude
   * 移动速度
   * 卫星数量
   * GPS 定位状态

9. **三类传感器联合运行**

   * MPU6050：浮标运动 / 姿态数据
   * BME280/BMP280：环境数据
   * G60 GNSS：位置与移动数据

10. **统一串口数据输出**

    * 提供适合直接查看的 `[DATA]` 数据
    * 保留适合后续电脑端程序解析的 `JSON` 数据结构

> V1.1 中的 roll / pitch 仍然主要根据加速度方向进行静态 / 低速倾角估算，并不是最终的姿态融合算法。浮标剧烈运动时会受到线性加速度影响，后续版本计划升级为互补滤波 / AHRS 等姿态融合算法。

## 当前版本结构

```text
ESP32-S3
│
├── I2C
│   ├── MPU6050
│   │   └── 加速度 / 角速度 / 倾角
│   │
│   └── BME280/BMP280
│       └── 温度 / 气压 / 湿度 / 高度
│
└── UART
    └── G60 GNSS
        └── 纬度 / 经度 / 速度 / 卫星数
```
